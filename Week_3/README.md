# Week 3 Task 1: CIFAR-10 Image Classification

This directory contains the Jupyter Notebook (`week_3_task_1_Anosh.ipynb`) for training a Convolutional Neural Network (CNN) on the CIFAR-10 dataset using TensorFlow and Keras.

## Model Performance
- **Final Test Accuracy:** 71.42% (0.7142)
- **Epochs Trained:** 12

## Overview
The model consists of three convolutional blocks followed by dense layers, designed to classify images into one of the 10 CIFAR-10 categories. The notebook includes data preprocessing, model architecture construction, training, evaluation, and visual predictions on sample test images.
