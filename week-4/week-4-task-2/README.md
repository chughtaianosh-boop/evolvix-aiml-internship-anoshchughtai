# IMDb Review Sentiment Analyzer

## Overview
This project is part of Week 4 - Task 2 of the Evolvix AI/ML Internship. It focuses on Natural Language Processing (NLP) to analyze the sentiment of IMDb movie reviews and classify them as positive or negative.

## Features
* Text preprocessing and cleaning of raw movie reviews.
* Sentiment classification using Machine Learning techniques.
* Evaluation of model accuracy and performance metrics.

## Tech Stack & Libraries
* Python 3.x
* Pandas & NumPy
* Scikit-Learn
* NLTK (Natural Language Toolkit)

## How to Run
1. Extract the project files from the provided `.zip` archive.
2. Activate the virtual environment (`.venv`).
3. Install the required dependencies (if any are missing).
4. Run the main Python script or Jupyter Notebook to see the sentiment analysis results.
